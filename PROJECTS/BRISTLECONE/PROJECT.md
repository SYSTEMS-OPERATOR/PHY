# BRISTLECONE Project Overlay

PHY-compatible comparison project for bristlecone pine material research.

Purpose: evaluate bristlecone pine as a reference case for slow-grown, long-duration wood behavior.

This project is comparative and research-oriented. Unknown material values must remain explicit.

Required outputs:

- reports/BRISTLECONE_BUILD_BOOK.md
- reports/BRISTLECONE_VALIDATION.md
- cutlists/bristlecone_cut_list.csv
- cutlists/drill_schedule.csv
- cutlists/hardware_cut_list.csv
- simulation/bristlecone_armature_urdf_like.json

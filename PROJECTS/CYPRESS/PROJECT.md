# CYPRESS Project Overlay

PHY-compatible comparison project for cypress material research.

Purpose: evaluate bald cypress and reclaimed cypress material as decay-resistant, stable wood candidates for armature components and long-duration fabrication.

Unknown material values must remain explicit.

Required outputs:

- reports/CYPRESS_BUILD_BOOK.md
- reports/CYPRESS_VALIDATION.md
- cutlists/cypress_cut_list.csv
- cutlists/drill_schedule.csv
- cutlists/hardware_cut_list.csv
- simulation/cypress_armature_urdf_like.json

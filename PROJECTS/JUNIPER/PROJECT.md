# JUNIPER Project Overlay

PHY-compatible comparison project for juniper material research.

Purpose: evaluate juniper species as durable, slow-grown wood candidates for armature components, inserts, joint blocks, and small articulated members.

Unknown material values must remain explicit.

Required outputs:

- reports/JUNIPER_BUILD_BOOK.md
- reports/JUNIPER_VALIDATION.md
- cutlists/juniper_cut_list.csv
- cutlists/drill_schedule.csv
- cutlists/hardware_cut_list.csv
- simulation/juniper_armature_urdf_like.json

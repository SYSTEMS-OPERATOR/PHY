# PHY Projects

Project overlays live here. Each project may define local material records, component guides, reports, cutlists, hardware schedules, and simulation artifacts without changing the universal PHY skeleton core.

## Shared reference

- `WOOD_BIBLE.md` defines the shared comparison vocabulary for wood-material projects.
- `material_record.template.json` defines the machine-readable material record contract.
- `component_guide.template.json` defines the machine-readable component guide contract.

## Wood comparison suite

- `DEFAULT/` — prototype and draft materials for test cuts and early validation.
- `REDWOOD/` — primary redwood armature project.
- `BRISTLECONE/` — bristlecone pine comparison and endurance reference project.
- `JUNIPER/` — juniper comparison project.
- `CYPRESS/` — cypress and reclaimed cypress comparison project.

## Composite armature projects

- `T56_CARBON/` — 1676.4 mm domestic humanoid armature using hybrid carbon-composite members, replaceable metallic joint cartridges, tendon-driven distal mechanisms, and compliant artificial fascia. The current scaffold is conceptual and explicitly not fabrication-ready.

## Rule

Project overlays may specialize fabrication assumptions locally. Universal PHY files remain species-agnostic.

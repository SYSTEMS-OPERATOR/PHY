# T-5.6 Shoulder Girdle Packet

Entry point: `shoulder_girdle_manifest.json`

The packet defines a project-local floating scapular girdle, clavicular guidance, removable humeral shoulder cartridges, sensor and service reservations, release gates, reference decomposition, and a staged validation plan.

Nothing in this packet is fabrication-ready. Unknown dimensions, loads, ranges, materials, safety factors, and acceptance criteria remain explicit release blockers.

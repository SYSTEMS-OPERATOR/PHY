# Bible Archive

This archive is for local offline assets used by the Wooden Armature Bible.

## Policy

Archive assets should be:

- source-traceable
- high-resolution where possible
- useful for design, fabrication, anatomy, mechanism, or historical precedent
- paired with a manifest record
- reviewed as KEEP or REJECT before inclusion in a generated PDF

## Current asset families

- `anatomical_plates/` — classical anatomical source-image targets and local import manifests.

## Binary image note

Image binaries should be imported by running the importer scripts in an internet-enabled checkout. The ChatGPT GitHub connector used during drafting can commit UTF-8 text manifests and scripts, but not raw binary image files through the normal file-create path.

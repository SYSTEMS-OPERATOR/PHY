# Charged Object Visual Archive

This directory is for visual-source manifests related to:

- `appendix_wooden_tulpa_precedents.md`
- `appendix_wooden_tulpa_visual_reference_index.md`

The archive covers tulpa-adjacent and charged-object precedents:

- nkisi / nkondi / minkisi power figures
- bocio / Vodun charged figures
- reliquary and hollow saint bodies
- poppets, charms, effigies, and protective objects
- Japanese doll / memorial / hitogata traditions
- Theosophical thoughtform plates
- transitional and memory objects
- carefully vetted haunted-object / spirit-vessel material

## Quality policy

High quality is preferred.

Standard quality is accepted when the object class is rare, culturally significant, or hard to source.

Low-quality, unsourced, sensational, or AI-generated imagery is rejected.

## Current files

- `visual_source_manifest.json` — curated source-page and image-link candidates for review.

## Import policy

Do not auto-import every candidate yet.

The charged-object archive should be reviewed before binary import because some objects may be culturally sensitive, rights-restricted, or better used as source links rather than embedded images.
